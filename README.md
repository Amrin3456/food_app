🍔 Food Ordering Application

React.js | Tailwind CSS | Context API

A modern food ordering web application with authentication, cart management, filtering, and checkout features. Built with a mobile-first responsive UI and global state management using Context API.

🔗 GitHub Repo: https://github.com/Amrin312/food_app


🚀 Features

- Add to Cart & Remove Items
- Checkout Flow
- Food Filtering & Search
- Global State Management using Context API
- Mobile-First Responsive UI with Tailwind CSS

🛠 Tech Stack

Frontend: React.js
Styling: Tailwind CSS
State Management: Context API
Routing: React Router
